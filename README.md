# Sajag Setu — Continuity of Care, Village to Hospital

Team A.C.E | Smart India Hackathon 2026 | Problem Statement SIH26133

## Problem
Rural patients face long travel, specialist shortages, and paper referrals 
with no tracking once a case leaves the sub-centre. Existing tools route 
to the next facility in line — not the nearest one actually capable of 
treating the case.

## What it does
- AI-assisted triage: maps reported symptoms to urgency + required capability
- Capability-aware routing: only routes to facilities that can actually treat the case
- Auto-escalation: unanswered referrals automatically move to the next capable facility
- Human override: ASHA workers/doctors can override AI suggestions, with reasoning logged
- Facility dashboard: real-time view of cases at each facility
- District officer view: read-only oversight of the whole referral network

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- Charts: Chart.js
